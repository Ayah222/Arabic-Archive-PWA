VIEW MODE REDESIGN – PROJECT DOCUMENTS



Modify the existing Project Documents section.



IMPORTANT:



* Remove all current document view modes.

* Keep only TWO view modes.

* Maintain RTL layout.

* Keep current design system.

* Keep Dark Mode and Light Mode compatibility.



==================================================

VIEW MODE 1 – GRID VIEW

=======================



Replace the current grid view with a professional document gallery.



GRID VIEW ICON



The first view mode must use an icon that clearly represents a visual gallery/grid layout.



Requirements:



* The icon should immediately communicate that documents will be displayed as cards arranged in a grid.

* Use a gallery-style or grid-style icon composed of multiple equal blocks.

* The icon should visually differentiate itself from the list view icon.

* When users see the icon, they should instantly understand that it switches to a card-based thumbnail view.



This view is intended to display document cards with large content previews, similar to image galleries, file managers, or media libraries.





Behavior:



When selected:



Display documents as large cards in a responsive grid.



Each card should contain:



* Large preview image

* Document Number

* Document Type

* Upload Date



==================================================

DOCUMENT PREVIEW IMAGE

======================



The preview image must come from the actual document content.



Examples:



Images:



* Display actual image thumbnail.



PDF:



* Generate thumbnail from first page.



Word Documents:



* Generate preview thumbnail from first page content.



Excel Files:



* Generate spreadsheet preview thumbnail.



Drawings:



* Display drawing preview image.



Do NOT use generic file icons as the main preview.



The content preview must be the dominant visual element.



==================================================

GRID CARD DESIGN

================



Card Layout:



Top:

Large preview image (70% of card height)



Bottom:



* Document Number

* Document Type

* Upload Date



Requirements:



* Large cards

* Modern spacing

* Hover animation

* Rounded corners

* Enterprise appearance



==================================================
