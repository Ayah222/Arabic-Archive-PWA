PROJECT PURPOSE

GLOBAL DOCUMENT NUMBERING SYSTEM
==================================================

Every document added anywhere in the system must automatically receive a unique sequential number.

Examples:

Images:

PIC-1
PIC-2
PIC-3

Reports:

REP-1
REP-2

Contracts:

CON-1
CON-2

The numbering must be GLOBAL across all projects.

Example:

Project A:
PIC-10

Project B:
PIC-11

Project C:
PIC-12

Do NOT restart numbering for each project.
