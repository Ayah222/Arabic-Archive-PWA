المطلوب: بناء البنية التحتية الأساسية لنظام إدارة الوثائق الهندسية (PWA) مع التحكم الكامل في المستخدمين والصلاحيات والإشعارات باستخدام Supabase للتوثيق وقواعد البيانات، مع الاعتماد الكامل على حسابات Gmail الحقيقية.
1. حساب مدير النظام الرئيسي (Real Admin Gmail):
•	تجهيز صفحة تسجيل الدخول (Login Page) لتعتمد بشكل أساسي على تسجيل الدخول عبر Google OAuth (Gmail) ويدوياً عبر البريد وكلمة المرور.
•	إعداد ربط Supabase Auth بحيث يتم التعرف على بريد مدير النظام الحقيقي (سنسجله في بيئة الإعدادات .env كـ ADMIN_EMAIL) وتعيين دور super_admin له تلقائياً في جدول profiles.
2. نظام دعوة الموظفين عبر Gmail والتحكم بالصلاحيات (Invite System):
•	إضافة موظف: واجهة للمدير يكتب فيها بريد Gmail الحقيقي للموظف، ليقوم النظام بإرسال إيميل دعوة رسمي (Email Invite) عبر Supabase Auth يحتوي على رابط تفعيل.
•	تحديد الصلاحيات عند الدعوة: يحدد المدير لكل موظف:
1.	إمكانية رفع الملفات والوثائق (can_upload).
2.	تاريخ ووقت انتهاء الوصول (access_expires_at).
3.	حالة الحساب: مفعل / مجمد (is_active).
•	التحقق المشدد من Google Login: إذا حاول أي شخص تسجيل الدخول بـ Gmail، يفحص النظام قاعدة البيانات؛ إذا كان بريده مدعواً ومجلساً من قبل المدير يفتح له النظام بالصلاحيات المحددة، وإذا لم يكن بريده مدعواً يُرفض الدخول مع عرض رسالة: "عذراً، هذا البريد غير مصرح له بالدخول، يرجى التواصل مع المدير".
3. لوحة إدارة المستخدمين (Admin Panel):
•	قائمة تعرض جميع الموظفين المسجلين والمستدعين مع إيميلاتهم.
•	إمكانية تعديل صلاحيات أي موظف فوراً، أو تجميد حسابه / إغلاقه بضغطة زر (is_active: false/true).
4. سجل التتبع والتدقيق (Audit Log):
•	ربط كل حدث (رفع ملف، تعديل، إضافة ملاحظة) ببريد الموظف واسمه والتاريخ والوقت بالثانية تلقائياً (created_by, created_at).
•	عرض اسم وتاريخ مَن قام بالتعديل أو الإضافة بوضوح تحت كل وثيقة أو قسم في الواجهة.
5. نظام الإشعارات والمعاينة المباشرة (Notifications System):
•	إنشاء جدول notifications يرسل الإشعار للمدير فوراً عند إضافة وثيقة أو ملاحظة من قبل موظف.
•	إضافة أيقونة جرس الإشعارات 🔔 في الشريط العلوي للمدير.
•	عند ضغط المدير على الإشعار، يتم توجيهه مباشرة لرؤية الوثيقة أو الملاحظة الجديدة لمعاينتها.
ملاحظة تقنية: يرجى إعداد الربط البرمجي مع Supabase وتفعيل سياسات الأمان (RLS) للتحقق من الأدوار، وتوفير واجهة عصرية متجاوبة مع الـ PWA.
