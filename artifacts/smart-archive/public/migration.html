ما هي هذه الأداة

ArchHive Migration أداة إدارية داخلية تخصّ شركة عبدالله نغيمش الأحمدي، وتُستخدم لنسخ مرفقات الأرشيف المحفوظة حالياً في تخزين ArchHive إلى مساحة Google Drive تملكها المؤسسة وتُديرها.

ليست خدمة عامة، ولا تملك تسجيل اشتراك، ولا واجهة للمستخدمين. لا يستطيع تشغيلها أو الإذن لها إلا مسؤول النظام المُخوَّل في المؤسسة، من جهاز يُديره بنفسه.

وجهة التخزين

الملفات المنسوخة تُحفظ في حساب Google Drive تابع للمؤسسة، داخل مجلد تُنشئه الأداة بنفسها. تبقى ملكية الملفات للمؤسسة، ولا تُشارك مع أي جهة خارجية، ولا تُنشر روابط عامة لها.

صلاحية الوصول المطلوبة

تطلب الأداة صلاحية واحدة فقط: https://www.googleapis.com/auth/drive.file

وهي صلاحية محدودة بالملفات التي تُنشئها الأداة نفسها. لا تستطيع الأداة رؤية أو فتح أو تعديل أو حذف أي ملف موجود مسبقاً في حساب Drive.

طريقة العمل: نسخ ثم تحقّق

  1. تقرأ الأداة الملف من تخزين ArchHive الحالي.
  2. تحسب بصمة SHA-256 للبايتات أثناء تدفّقها.
  3. تُنشئ الملف في مجلد الوجهة، بمعرّف محجوز مسبقاً يمنع التكرار عند إعادة

المحاولة.

  1. تقرأ بصمة النسخة في Drive وتُقارنها بالبصمة المحسوبة.
  2. عند أي اختلاف يُعلَّق الملف ويُسجَّل، ويبقى الأصل كما هو دون مساس.

لا تحذف الأداة أي ملف من المصدر في أي مرحلة.

حماية مرفقات العملاء

  • الأصول في ArchHive تبقى موجودة ولا تُحذف ولا تُعدَّل.
  • لا تُغيَّر مراجع الملفات في قاعدة البيانات ضمن عمل هذه الأداة.
  • لا يُعدّ أي ملف منقولاً إلا بعد نجاح التحقّق من سلامته.
  • عزل المستأجرين محفوظ: يحتفظ كل ملف منسوخ بوسم المستأجر نفسه المستخدم حالياً.
  • السجلات تحتوي بصمات وأحجاماً وحالات فقط — لا أسماء ملفات ولا محتوى.

علاقتها بخدمة ArchHive

أداة مستقلة ومنفصلة. لا تُعدّل تطبيق ArchHive المنشور، ولا إعداداته، ولا اعتماداته. اعتماد الدخول الخاص بها منفصل تماماً عن اعتماد الخدمة الذي يستخدمه التطبيق، ولا يعتمد مستخدمو ArchHive العاديون عليه إطلاقاً.

الحالة الراهنة: هذه الصفحة تعريفية. لم يبدأ أي ترحيل، ولم يُنسخ أي ملف.

What this is

ArchHive Migration is an internal administrative utility belonging to شركة عبدالله نغيمش الأحمدي. It copies archive attachments currently held in ArchHive storage into a Google Drive space owned and controlled by the institution.

It is not a public service. It has no sign-up, no end-user interface, and no public users. Only the institution's authorised administrator can operate or authorise it, from a machine that administrator controls.

Storage destination

Copied files are placed in an institution-owned Google Drive account, inside a folder the utility creates itself. The institution retains ownership. Files are not shared with third parties and no public links are created.

Access requested

A single scope: https://www.googleapis.com/auth/drive.file — per-file access limited to files the utility itself creates. The utility cannot see, open, modify or delete any pre-existing file in the Drive account.

How it works: copy, then verify

  1. Read the file from existing ArchHive storage.
  2. Compute a SHA-256 digest over the bytes as they stream.
  3. Create the file in the destination folder, using a pre-reserved file ID so a

retry cannot produce a duplicate.

  1. Read the destination checksum back from Drive and compare.
  2. On any mismatch the file is parked and recorded, and **the original is left

untouched**.

The utility never deletes anything from the source, at any stage.

Protection of customer attachments

  • Originals in ArchHive remain present, unmodified and undeleted.
  • Database file references are not altered by this utility.
  • No file counts as migrated until its integrity check passes.
  • Tenant isolation is preserved: each copied file keeps the same tenant tag.
  • Logs contain digests, sizes and states only — never file names or content.

Relationship to the ArchHive service

Separate and independent. It does not modify the published ArchHive application, its configuration or its credentials. Its sign-in credential is entirely separate from the service credential the application uses, and ordinary ArchHive users never depend on it.
