# أرشيف ذكي — Smart Archive PWA

## Overview

A Progressive Web App (PWA) for entrepreneurs and contractors to manage construction/business project archives. Features full Arabic RTL UI, mobile-first design, CRUD for projects with 5 sub-sections, microphone command processing, and file uploads.

## Architecture: MVC Pattern

| Layer | Location | Responsibility |
|-------|----------|----------------|
| **Models** | `src/models/` | TypeScript interfaces, label maps, formatters |
| **Views** | `src/views/` | React components: pages, layouts, shared UI |
| **Controllers** | `src/controllers/` | Custom hooks wrapping generated React Query hooks |

API client hooks are generated from `lib/api-spec/openapi.yaml` via Orval codegen.

## API Endpoints

Base path: `/api/sa/`

| Method | Path | Description |
|--------|------|-------------|
| GET | `/sa/dashboard` | Stats + recent projects |
| GET/PATCH | `/sa/notifications` | List + mark as read |
| GET/POST | `/sa/projects` | List (filterable) / Create |
| GET/PATCH/DELETE | `/sa/projects/:id` | Get / Update / Delete |
| GET/POST | `/sa/projects/:id/contracts` | List / Create |
| PATCH/DELETE | `/sa/projects/:id/contracts/:cid` | Update / Delete |
| GET/POST | `/sa/projects/:id/contractors` | List / Create |
| PATCH/DELETE | `/sa/projects/:id/contractors/:cid` | Update / Delete |
| GET/POST | `/sa/projects/:id/documents` | List / Create |
| DELETE | `/sa/projects/:id/documents/:did` | Delete |
| GET/POST | `/sa/projects/:id/meetings` | List / Create |
| PATCH/DELETE | `/sa/projects/:id/meetings/:mid` | Update / Delete |
| GET/POST | `/sa/projects/:id/letters` | List / Create |
| DELETE | `/sa/projects/:id/letters/:lid` | Delete |
| POST | `/sa/upload` | File upload (multipart/form-data) |
| POST | `/sa/voice` | Arabic voice command processing |

## Data Storage

Currently uses **in-memory mock data** (initialized in `artifacts/api-server/src/routes/sa/store.ts`) with 3 sample projects and related records. Data resets on server restart.

**To connect a real database:**
1. Add PostgreSQL + Drizzle schema in `lib/db/`
2. Replace `store.ts` reads/writes with Drizzle queries
3. Set `DATABASE_URL` environment variable

## Features

- ✅ Full CRUD for projects
- ✅ 5 sub-sections per project: Contracts, Contractors, Documents, Meetings, Letters
- ✅ File upload UI (drag-and-drop, stored in `uploads/`)
- ✅ Microphone button (Arabic NLP stub; connects to Whisper if `VITE_OPENAI_API_KEY` is set)
- ✅ Dashboard with stats and progress bars (no chart libraries)
- ✅ Arabic RTL layout with Tajawal font
- ✅ Mobile-first: bottom tab bar + floating mic button
- ✅ Desktop: sidebar navigation
- ✅ PWA manifest for installability
- ✅ OpenAPI contract-first API with generated React Query hooks

## Development Commands

```bash

pnpm --filter @workspace/api-spec run codegen

pnpm --filter @workspace/smart-archive run typecheck
```
